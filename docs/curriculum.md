# 德州扑克专业级教学 App —— 课程大纲

目标：把一个零基础/业余玩家，按可验证的阶梯，训练到能稳定盈利的准职业水平（现金局 + 锦标赛）。
形态：移动端微课（每课 5–10 分钟）+ 每课配套 drill + 每日训练 + 错题本。

---

## 二、逐级明细

### L0 地基：规则与语言
1. 牌桌构成、盲注、行动顺序
2. 牌型大小与比牌规则（含踢脚牌/公牌成牌）
3. 位置：BTN / CO / HJ / LJ / UTG / SB / BB 与位置价值
4. 下注结构：limp / raise / 3bet / 4bet / 5bet，尺度记法（bb, %pot）
5. 街的划分：Preflop / Flop / Turn / River，及每街的决策性质
6. 常用术语表（中英对照，可检索）
7. 现金局 vs 锦标赛的根本差异
8. 一手牌完整走读（带标注回放）

### L1 翻前基础
1. 起手牌分类：对子 / 同花连张 / Ax / 破牌
2. 13×13 范围矩阵读法与写法
3. 位置对开池范围的影响（RFI 表：6max / 9max）
4. 面对开池：3bet / call / fold 的划分逻辑
5. 极化 3bet vs 线性 3bet
6. 4bet / 5bet 与全下阈值
7. 冷跟注（cold call）何时成立
8. 盲注防守：BB 防守范围与底池赔率
9. SB 策略：limp 体系 vs 纯 raise 体系
10. 筹码深度对翻前的影响（20bb / 40bb / 100bb / 200bb）
11. Squeeze（挤压）与多人底池翻前
12. 翻前常见 leak 清单

配套 drill：**范围训练器**（随机位置 + 动作，回答 raise/call/fold，即时对照标准范围）

### L2 扑克数学
1. Outs 与 4-2 法则
2. 底池赔率（pot odds）与必要胜率
3. Equity 概念：手牌 vs 手牌、手牌 vs 范围
4. 隐含赔率与反向隐含赔率
5. EV 公式与手算流程
6. 弃牌率盈亏平衡点（breakeven bluff %）
7. MDF（最小防守频率）与 α
8. 价值下注的盈亏平衡（被跟注范围）
9. 组合数学：blockers 与组合计数（combos）
10. 方差、标准差与样本量直觉

配套 drill：**赔率闪卡**（限时）、**EV 计算题**、**Combo 计数题**

### L3 翻后基础
1. 牌面结构分类：干燥 / 湿润 / 连牌 / 同花面 / 配对面
2. 范围优势 vs 坚果优势
3. C-bet 的判断框架（谁的范围更好？）
4. 下注尺度体系：33% / 50% / 75% / 125%+ 各自的用途
5. 作为翻前加注者在有位/无位的差异
6. 面对 c-bet：跟注 / 加注 / 弃牌的构建
7. 听牌的打法：半诈唬频率与尺度
8. 慢打的正确与错误场景
9. 多人底池的收缩原则
10. 检查-加注（check-raise）体系
11. 顶对类牌的街数规划（planning streets）
12. 保护 vs 不需要保护
13. 弃牌权益（fold equity）估算
14. Flop 常见错误清单

配套 drill：**Board Texture 分类题**、**Flop 决策训练**

### L4 进阶翻后：Turn / River
1. Turn 的牌面变化分类（brick / 完成听牌 / 配对 / 高牌）
2. 二枪（double barrel）的选择标准
3. 转牌尺度放大与极化
4. 延迟 c-bet（delayed c-bet）
5. 浮牌（float）与偷底池
6. Blockers 与 unblockers 在诈唬选择中的应用
7. River 价值下注：薄价值的边界
8. River 诈唬：频率、组合选择、尺度
9. 面对 river 大注的 bluff-catch 决策
10. 河牌加注与超池下注
11. 无位的检查-跟注范围构建
12. 全街下注树（bet tree）的心智模型
13. 单挑（HU）与三人底池的差异
14. 转河常见错误清单

配套 drill：**转河 spot trainer**（多选 + 解析 + solver 频率对照）

### L5 读牌与对手建模
1. 范围构建：从翻前到河牌的逐街收窄
2. Hand reading 五步法（标准流程）
3. 玩家分类：TAG / LAG / 鱼 / 岩石 / 疯子
4. 核心统计：VPIP / PFR / AF / 3bet% / CBet% / WTSD / Fold to CBet
5. HUD 读法与样本量陷阱
6. 下注尺度中的信息泄漏（sizing tell）
7. 时序 tells（线上）与生理 tells（线下）
8. 表格化笔记系统（note taking）
9. 反向读牌：我的范围在对手眼里是什么
10. 桌面动态与形象管理

配套 drill：**范围推断题**（给出行动线，画出对手范围矩阵）

### L6 GTO 与剥削
1. 纳什均衡在扑克中的含义
2. 无差异点（indifference）与混合策略
3. 为什么需要频率而不是"这手怎么打"
4. Solver 输出的读法（EV / 频率 / 尺度分布）
5. 简化策略树：把 solver 压缩成人能执行的规则
6. 从 GTO 偏离：对手 leak → 剥削调整对照表
7. 过度弃牌的对手：如何加大诈唬
8. 跟太多的对手：如何砍诈唬、加薄价值
9. 被剥削的风险与还原（re-exploitation）
10. 节点锁定（node locking）思路
11. 何时该 GTO、何时该剥削（决策规则）
12. 常见"伪 GTO"误解澄清

配套 drill：**频率题**、**剥削调整题**（给出对手统计，选调整方向）

### L7 锦标赛
1. MTT 结构：级别、平均筹码、M 值与筹码深度
2. Ante 对策略的影响
3. 短筹码：Push/Fold 与 Nash 表
4. 中等筹码的 re-shove 范围
5. ICM 基础：筹码 ≠ 金钱
6. 泡沫期策略与 ICM 压力
7. 最终桌：奖金跳跃与保守/激进的切换
8. 大筹码的施压打法
9. Satellite（卫星赛）的特殊策略
10. 重买 / 增购 / 后期注册的期望值
11. SNG 与 Spin 的差异
12. MTT 常见错误清单

配套 drill：**Push/Fold 训练**、**ICM 决策题**

### L8 现金局深度打法
1. 100bb 与 200bb+ 的策略差异
2. Straddle / 有 limper 桌的调整
3. 桌选择与座位选择（seat selection）
4. Rake 对策略的实际影响（尤其微额）
5. 多桌管理与决策简化
6. Zoom / 快速桌的调整
7. 线下现金局的节奏与差异
8. 从微额到中额的升级路线

### L9 心态与资金管理
1. Bankroll 规则（现金局 / MTT 分别的 buy-in 数）
2. 方差的真实感受与下行区间
3. Tilt 识别与分类
4. Tilt 应对流程（stop-loss、呼吸、离桌规则）
5. Session 准备与结束仪式
6. A 游戏 / B 游戏 / C 游戏 的自我评估
7. 复盘流程标准化（每 session 3 手）
8. 学习循环：输入 → 练习 → 实战 → 复盘

### L10 职业化工作流
1. 数据库工具（PT4 / HM3）基础
2. 关键报表与筛选器
3. Leak finding 方法论
4. Solver 使用流程（建树、简化、批量分析）
5. 每周训练计划模板
6. 目标设定与 KPI（bb/100、ROI、学习时长）
7. 常见 leak 库与对应练习
8. 独立复盘报告：从数据到行动项

## 五、移动端形态要点

- 竖屏优先，单手可操作；13×13 矩阵支持拖拽涂抹选择
- 牌面用真实卡牌可视化，不用纯文字
- 每课 5–10 分钟，通勤可完成
- 闯关式解锁 + 进度条 + 连续打卡
- 离线可用（课程与题库本地缓存）
- 深色模式（牌桌绿/黑主题）
- 手牌回放器：可逐街前进/后退，显示底池、赔率、范围

---

## 六、学习路径建议

- **快速上桌路线（2 周）**：L0 → L1 → L2 → L3 精简版
- **系统路线（3–6 个月）**：L0 → L10 顺序推进，每周 2–3 课 + 每日训练
- **锦标赛专精**：L0–L5 → L7 → L6
- **现金局专精**：L0–L6 → L8 → L9 → L10

---

## 七、内容正确性原则

- 所有范围表、频率、Push/Fold 表标注来源与假设（人数、筹码深度、rake、ante）
- 区分「共识标准」与「简化近似」，简化处明确说明代价
- 不给无来源的精确数字；给不出就说明是经验区间
